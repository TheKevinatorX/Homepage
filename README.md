## Prerequisites

Before using these configurations in your setup, ensure you have the following:

- Docker engine installed on your system.
- Docker socket configured. See Homepage Wiki.
- A `.env` file with your own variables.

- widgets.yaml
- `/Images` directory (If you like the background)
